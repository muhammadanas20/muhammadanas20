# Definition of done

A phase is not done because you "got the idea."

Use this checklist. Be harsher than a kind mentor. Kind mentors still have to reject pull requests.

---

## A lesson is done when

- [ ] You can explain the idea to a rubber duck without opening the notes
- [ ] You typed the example, ran it, and changed one parameter to see what breaks
- [ ] You can name one case where you should **not** use this technique
- [ ] You attempted the quiz cold
- [ ] You answered at least five interview questions out loud

---

## A phase is done when

- [ ] All `★` files in the phase README are complete
- [ ] Mini-project is in **your** GitHub, not only this folder
- [ ] README of that project has: problem, architecture diagram, how to run, limitations
- [ ] You recorded rough numbers: latency, token use, or eval score
- [ ] You wrote five lines in your progress tracker about what was surprisingly hard

---

## A project is portfolio-ready when

- [ ] `README.md` that a hiring manager can skim in 90 seconds
- [ ] Architecture Mermaid diagram
- [ ] `.env.example` and no secrets in git history
- [ ] `docker compose up` or a one-command install
- [ ] Tests or an eval set — even 20 questions
- [ ] A "What I would do next" section (shows seniority)
- [ ] License file

If it only runs in a notebook with cells executed out of order, it is a draft.

---

## The capstone is done when

- [ ] Live URL or a recorded demo if the host sleeps
- [ ] Design doc (see [SYSTEM_DESIGN_GUIDE.md](./SYSTEM_DESIGN_GUIDE.md))
- [ ] Threat model (Phase 13)
- [ ] Eval table
- [ ] Cost estimate per 1,000 requests
- [ ] Resume bullet that names the constraint you solved (latency, cost, quality, or safety)

---

## You are "applying for jobs" ready when

- [ ] Phases 0–8 solid (RAG you can defend)
- [ ] At least one of 9–10 (agents or MCP)
- [ ] One deployed service (Phase 11)
- [ ] You can whiteboard RAG in 15 minutes
- [ ] You can debug a failing tool call without panic
- [ ] Resume matches [RESUME_GUIDE.md](./RESUME_GUIDE.md)

You do **not** need every vector database. You need one you can operate and the vocabulary to compare the others.

---

## Honesty clause

If you used an AI assistant to write code (good — you will at work):

- [ ] You can explain every file
- [ ] You deleted the parts you do not understand and rewrote them
- [ ] You did not paste a key into the chat

Assistants are tools. Interviews still ask *you*.
