# Behavioral (STAR)

Prepare six stories from this course:

1. **A production bug** — SSE buffering, tenant leak test, dimension mismatch
2. **Said no to scope** — skipped GraphRAG to finish evals
3. **Disagreement** — teammate wanted an agent; you shipped a chain and measured
4. **Wrong** — mixed embedding models, random retrieval, you wrote a test
5. **Ambiguous requirements** — you asked about latency and risk first
6. **Taught someone** — a README a classmate followed without you

STAR: Situation, Task, Action, Result (a number if possible). 90 seconds each.
