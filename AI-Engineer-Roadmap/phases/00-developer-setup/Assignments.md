# Assignments — Phase 0: Developer setup

These mimic take-homes. Time-box them. A finished 80% with a README beats an infinite 99%.

## Assignment 1. Onboarding README

**Time box:** 90 minutes

Pretend a new intern starts Monday. Write a README for a fake service that includes OS support, Python version, venv, Docker, and how to run tests. No fluff.

### Deliverables

- README.md
- screenshot of sanity.py output
- .env.example

### Rubric

- A stranger can follow it without Slack
- Secrets are named, not pasted
- Windows + macOS + Linux considered


## Academic integrity

You may use an assistant. You must be able to delete `main.py` and rewrite it from memory the next morning. Interviews will ask you to.
