# Practice — Phase 0: Developer setup

Guided drills. Timer on. No tutorial hopping.



### Drill 1. Fifteen-minute terminal gym

Create `~/ai-lab/tmp`, make a file, pipe `echo hello | wc -c`, then `false; echo $?`. Write down the exit code.

**Done when:** `$?` after `false` is 1, and you are not scared.

### Drill 2. Venv muscle memory

Create `.venv`, activate, `pip install ruff`, `which python`, deactivate, `which python` again. The path must change.

**Done when:** You can do it without looking at notes.

### Drill 3. Git loop

Branch `practice/setup`, commit `sanity.py`, push, open a PR, merge, pull `main`.

**Done when:** GitHub shows the PR.

## Cool-down

Explain today's idea to a rubber duck in 90 seconds using the analogy from Theory.md. If you need the file open, you are not done.
