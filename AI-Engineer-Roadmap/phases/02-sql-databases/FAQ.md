# FAQ — Phase 2: SQL, Postgres, and Redis

### SQLite enough?

For Phase 2 drills on a plane, yes. For Compose + Redis drills, use Postgres. pgvector and production features differ.

### ORM or raw SQL?

Learn SQL first. Then SQLAlchemy. Never only an ORM you cannot see through.

### Do I need Kafka?

No.
