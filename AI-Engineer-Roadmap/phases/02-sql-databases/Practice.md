Guided drills. Timer on. No tutorial hopping.

**Done when:** You used EXPLAIN at least twice.

### Drill 2. Redis CLI

**Done when:** You saw a key vanish after TTL.

### Drill 3. Migration

**Done when:** Upgrade and downgrade scripts exist.
