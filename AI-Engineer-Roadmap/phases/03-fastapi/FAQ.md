# FAQ — Phase 3: FastAPI

### Flask instead?

Fine if you already know it. This course uses FastAPI because typing + async + OpenAPI match AI services.

### Do I need HTTPS locally?

No. In production, yes, usually via a proxy.

### python-jose vs PyJWT?

Either. Be consistent. Know the algorithms you allow.
