# Practice — Phase 3: FastAPI

Guided drills. Timer on. No tutorial hopping.



### Drill 1. OpenAPI

Build three routes. Screenshot /docs. Download the OpenAPI JSON.

**Done when:** A client could be generated from it.

### Drill 2. TestClient

Write two tests: 401 without token, 200 with.

**Done when:** pytest -q green.

### Drill 3. Request ID

Middleware that sets X-Request-ID uuid if missing and logs it.

**Done when:** You can grep logs by id.
