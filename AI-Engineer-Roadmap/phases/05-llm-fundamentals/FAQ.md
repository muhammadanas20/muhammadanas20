# FAQ — Phase 5: LLM fundamentals

### I have no API budget.

Ollama + a small model. Groq free tiers sometimes exist. This phase works locally.

### Which model?

The cheapest that passes your eval. Record the name and date.

### Is ChatGPT Plus enough?

The web UI is not an API. You cannot version, log, or evaluate it like a component.
