# Practice — Phase 5: LLM fundamentals

Guided drills. Timer on. No tutorial hopping.



### Drill 1. Token gym

Install tiktoken or use Ollama's token count. Measure 3 strings: English, code, Urdu/emoji. Write the ratios.

**Done when:** You stopped believing 1 word = 1 token.

### Drill 2. Temperature

Same extraction prompt at 0 and 1.0, 10 times each. Count schema failures.

**Done when:** A small table.

### Drill 3. Ollama or hosted

Run one chat completion locally or on a free/cheap API. Log tokens and latency.

**Done when:** A line in NOTES/.

## Cool-down

Explain today's idea to a rubber duck in 90 seconds using the analogy from Theory.md. If you need the file open, you are not done.
