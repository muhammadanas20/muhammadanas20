# Practice — Phase 6: Embeddings and search

Guided drills. Timer on. No tutorial hopping.



### Drill 1. Nearest neighbor by hand

Draw 5 points on paper in 2D. Query point. Rank cosine vs L2 if one vector is very long.

**Done when:** You can say when L2 and cosine disagree.

### Drill 2. Break a table

Chunk a Markdown table with a 40-char window. Read the chunks. Feel the pain.

**Done when:** You refuse to ship that splitter.

### Drill 3. Grep vs semantic

Find a paraphrase in this course that grep misses and embeddings catch.

**Done when:** One screenshot or note.
