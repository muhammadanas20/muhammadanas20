# FAQ — Phase 7: Vector databases

### Must I learn all six?

No. Hands-on two (Chroma + pgvector). Read the others enough to compare. That is the exit ticket.

### Redis vector search?

Exists (RediSearch). Fine as a cache of vectors, not usually your system of record.

### Elasticsearch/OpenSearch kNN?

Valid if the company already runs them. Not our default.
