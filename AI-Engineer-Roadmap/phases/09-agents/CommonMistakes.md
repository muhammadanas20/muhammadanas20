# Common mistakes — Phase 9: Agents

### 1. Agent-washing a form

A form with 3 fields became a 6-agent crew.

**Do this instead:** HTML form or a chain.

### 2. Policy in the prompt only

Model refunds anyway.

**Do this instead:** Eligibility in Python; model proposes.

### 3. Swallowing tool errors

Model invents the order status.

**Do this instead:** Pass the error back; maybe stop.

If you invent a new mistake, add it here in a PR. That is how this file stays alive.
