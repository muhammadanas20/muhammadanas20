# Common mistakes — Phase 10: Model Context Protocol (MCP)

### 1. MCP as a personality

It's plumbing.

**Do this instead:** Talk about discovery and auth.

### 2. One server with 80 tools

The model chooses poorly.

**Do this instead:** Small servers per domain.

### 3. No human approval for writes

IDE agent deletes files.

**Do this instead:** Confirm UX + split read/write servers.

If you invent a new mistake, add it here in a PR. That is how this file stays alive.
