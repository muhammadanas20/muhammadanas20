# FAQ — Phase 10: Model Context Protocol (MCP)

### MCP vs OpenAPI?

OpenAPI describes HTTP APIs for any client. MCP describes tools/resources for model hosts. You can wrap OpenAPI with MCP.

### MCP vs LangGraph tools?

LangGraph is a runtime. MCP is a distribution protocol. Use both: graph calls MCP tools.

### Do I need Anthropic?

No. MCP is open. Many hosts speak it.
