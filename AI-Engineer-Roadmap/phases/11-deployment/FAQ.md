# FAQ — Phase 11: Deployment

### Which PaaS?

The one whose free tier is alive this month. Fly/Render/Railway are all fine. Pick one and finish.

### AWS required?

For some jobs. Learn the map (ECS/EKS/Lambda/RDS). Don't boil the ocean before you have a URL.

### GPU?

Not for calling OpenAI. Only if you self-host models.
