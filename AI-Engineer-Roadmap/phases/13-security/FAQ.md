# FAQ — Phase 13: Security

### Can we ever fully prevent injection?

Not while instructions and data share a token stream. Reduce blast radius.

### Is a safety classifier enough?

No.

### Should we ban users who inject?

Log, rate limit, maybe. Still fix the system. Attackers aren't only logged-in users — docs can be the attacker.
